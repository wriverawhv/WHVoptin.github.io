# JNL Quantum Wireless Call Alarm SMS Notifications

## Opt-In to Receive SMS Text Messages

We want to send you important resident call alarm notifications via SMS text messages to keep you informed in real-time.

### What SMS Messages You Will Receive

By opting in, you will receive text message alerts for:

- **Resident call button activations** – When residents press their call buttons
- **Wireless nurse call station alerts** – From portable call devices
- **JNL Quantum system alarms** – System-level notifications and emergencies

You can expect approximately **5–20 text messages per day** depending on call volume.
